EpicDirectories provides a curated catalog of 165 directories, databases, and searchable archives across various categories such as entertainment, SaaS, business, education, and more. The platform helps users discover valuable resources for research, development, and market insights, offering categorized listings with screenshots and detailed information to streamline the search for relevant directories and data sources.

**Areas:** Company · Directory · Data · Catalog · Search

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for EpicDirectories: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
